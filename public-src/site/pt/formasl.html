01 / Tipos, relações e ClaimsFORMA

Declarar o domínio

Tipos definem categorias. Relações estabelecem os papéis que os participantes ocupam. Claims registram atos atribuíveis de afirmação. A linguagem mantém essas responsabilidades distintas.

Veja o contrato escrito

Os exemplos mostram declarações, consultas, regras e transformações retiradas de arquivos documentados. São excertos didáticos, não uma execução no navegador.

examples/F02-nary-semantic-roles/canonical.fsl
module semantic_roles {
    type Agent
    type Artifact
    type Project
    type Environment

    relation Assignment {
        role assignee: Agent
        role artifact: Artifact
        role project: Project
        role environment: Environment
    }

    assert claim a1 : Assignment(
        assignee: $alice,
        artifact: $dataset,
        project: $atlas,
        environment: $production
    ) { by : $registry }
}

examples/F05-reasoning-completion/canonical.fsl
rule Base using DependsOn(?x: Artifact) {
    when DependsOn(dependent: ?a, prerequisite: ?b)
    derive positive ReachableDependency(
        dependent: ?a, prerequisite: ?b
    )
}

rule Step using DependsOn(?x: Artifact) {
    when DependsOn(dependent: ?a, prerequisite: ?b)
    when ReachableDependency(dependent: ?b, prerequisite: ?c)
    derive positive ReachableDependency(
        dependent: ?a, prerequisite: ?c
    )
}

03 / Famílias do FormaSLFORMA

Operações de naturezas diferentes

match consulta relações; rule e infer derivam consequências; analyze realiza cálculos e modelos; transform constrói estruturas; validate, admit, authorize e decide tratam critérios e responsabilidades; scenario e composition permitem exploração e combinação governadas.

type / relation

Definem categorias e os papéis de cada relação.

assert claim

Introduz uma afirmação atribuível e identificável.

match

Consulta padrões, caminhos e agregações.

rule / infer

Deriva consequências sob regras e teorias.

analyze

Executa análises, estatísticas e modelos, inclusive grafos e GNNs.

transform

Produz estruturas a partir de correspondências declaradas.

validate / admit

Aplica critérios e controla a admissão de resultados.

authorize / decide

Distingue autorização de escolha responsável.

scenario

Avalia cenários hipotéticos.

composition

Combina operações com dependências explícitas.

04 / Execução e limitesFORMA

Do fonte à avaliação

A fonte pode ser verificada e inspecionada antes de uma operação ser executada. Um orçamento chamado gas limita o trabalho lógico. Uma execução incompleta não equivale a uma conclusão falsa. Uma decisão não implica que a ação externa tenha ocorrido.
