Declare the domain

Types define categories. Relations specify the roles participants may occupy. Claims record attributable acts of assertion. The language keeps these responsibilities separate.

examples/F02-nary-semantic-roles/canonical.fsl
module semantic_roles {
    type Agent
    type Artifact
    type Project
    type Environment

    relation Assignment {
        role assignee: Agent
        role artifact: Artifact
        role project: Project
        role environment: Environment
    }

    assert claim a1 : Assignment(
        assignee: $alice,
        artifact: $dataset,
        project: $atlas,
        environment: $production
    ) { by : $registry }
}
CONCEPTUAL DEMONSTRATION

Four roles. One relation.

Assignment brings four typed participants into one occurrence. A Claim records the attributable statement.

examples/F05-reasoning-completion/canonical.fsl
rule Base using DependsOn(?x: Artifact) {
    when DependsOn(dependent: ?a, prerequisite: ?b)
    derive positive ReachableDependency(
        dependent: ?a, prerequisite: ?b
    )
}

rule Step using DependsOn(?x: Artifact) {
    when DependsOn(dependent: ?a, prerequisite: ?b)
    when ReachableDependency(dependent: ?b, prerequisite: ?c)
    derive positive ReachableDependency(
        dependent: ?a, prerequisite: ?c
    )
}

03 / FormaSL operation familiesFORMA

Operations with distinct meanings

match queries relations; rule and infer derive consequences; analyze computes results and models; transform constructs new structures; validate, admit, authorize and decide govern criteria and responsibility; scenario and composition support hypothetical evaluation and controlled combination.

type / relation

Define categories and relation roles.

assert claim

Introduce an identifiable attributable statement.

match

Query patterns, paths and aggregations.

rule / infer

Derive consequences under declared theories.

analyze

Run analysis, statistics and models, including graph algorithms and GNNs.

transform

Construct structures from declared correspondences.

validate / admit

Evaluate criteria and govern admission.

authorize / decide

Keep authorization distinct from accountable decisions.

scenario

Evaluate hypothetical conditions.

composition

Combine operations with explicit dependencies.

04 / Execution and limitsFORMA

From source to evaluation
