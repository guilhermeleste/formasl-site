Programming languages are excellent at telling machines how to execute. Schemas describe structures. Ontologies define concepts. An independent layer for meaning needs to declare the world that software intends to make computable.

FormaSL — Forma Semantic Language — was created for that purpose.

A FormaSL contract describes concepts, relations, context, authority, time, claims, rules and semantically relevant operations. That description remains independent from the database, service, model or infrastructure chosen to realize it.

This changes the starting point of development. Instead of always beginning with infrastructure primitives and allowing meaning to emerge from their composition, we can begin with the domain and the rules that define it.

The language does not turn a declaration into truth about reality. It turns declared meaning into something explicit, computable and verifiable.

**If meaning has its own layer, it also needs a language of its own.**
