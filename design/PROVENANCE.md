# Asset provenance and visual baseline

The institutional website was authored in this conversation from the user-supplied original presentation (Slide sem titulo (2).pptx) and the approved v0.5/v0.6 site previews. The three mineral images, the site styles, and the site scripts are in `public-src/site/assets/`.

The mdBook theme overlay draws on the approved website tokens:

- paper #efe8dd
- deep paper #e7ded1
- ink #192122
- dark slate #182123
- copper #bc8865

Fonts are not embedded or redistributed. The CSS uses system and installed fallbacks, including CJK fallbacks where available.

Publication must be preceded by the owner's confirmation that all visual assets in the original slides may be used on the public website. This package does not contain or distribute proprietary font files.

The design screenshots are illustrative references; the production site is the static HTML in `public-src/site`, and the mdBook styling is supplied by `docs-theme/forma-docs.css` and `forma-docs-toc.js`.
